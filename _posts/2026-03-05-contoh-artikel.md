Selamat datang di **Blogjak Theme Versi 2**! Artikel ini memperlihatkan bagaimana Anda cukup menulis berkas Markdown biasa di folder `_posts/` untuk mempublikasikan konten. Tidak perlu menyunting JSON, tidak perlu membuat HTML manual.

## 🚀 Alur Kerja Pure Markdown

Untuk menambah artikel baru, cukup ikuti langkah berikut:

1. Buat berkas di `_posts/` dengan nama `YYYY-MM-DD-judul-artikel.md`
2. Isi **front matter** (di antara `---`)
3. Tulis konten dalam Markdown

```yaml
---
layout: post
title: "Judul Artikel Anda"
description: "Deskripsi singkat untuk preview galeri."
date: 2026-03-05 09:00:00 +0700
categories: [Tutorial]
tags: [markdown, jekyll]
image: "https://example.com/gambar.jpg"
---
